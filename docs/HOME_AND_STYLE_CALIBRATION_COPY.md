## 2. Test de estilo

### Nombre dentro del producto

**Calibración inicial**

“Test de estilo” puede usarse para adquisición o SEO, pero dentro del producto conviene llamarlo “calibración”: no existe una respuesta correcta, no encasilla a la persona y puede cambiar con ella.

### Objetivo

Dar a Formé un punto de partida útil para recomendar looks sin convertir género, estilo o una familia visual en restricciones absolutas.

### Duración esperada

3 minutos.

### Principios

- Una preferencia no es lo mismo que un límite.
- El lenguaje de presentación orienta; no bloquea categorías.
- Las afinidades visuales ordenan recomendaciones; no definen a la persona.
- Los límites explícitos siempre tienen prioridad.
- La calibración inicial se conserva como punto de partida.
- Los looks guardados, descartados y usados forman después una capa de aprendizaje separada.

Punto de partida

### Paso 2 — Afinidades visuales

Se presenta una dirección por pantalla mediante looks completos. No se anuncia “12 familias” como beneficio ni se muestra una matriz de etiquetas.

**Pregunta constante**

¿Cuánto usarías algo así?

**Control**

Escala de 0 a 100:

- 0 — Nunca
- 50 — A veces
- 100 — Sí, mucho

**Acciones**

- Siguiente
- No quiero ver esto

Si la respuesta está entre 0 y 25, o si se elige “No quiero ver esto”:

**Seguimiento**

¿Qué no te funciona?

**Motivos**

- Color
- Silueta
- Combinación
- Formalidad
- Expresión
- Ajuste
- Calzado
- Prenda específica

#### Direcciones y textos

**Clásico**

Piezas atemporales, líneas claras y combinaciones que no dependen de una temporada.

**Minimalista**

Paleta contenida, pocos elementos y proporciones precisas.

**Relajado**

Capas cómodas, volúmenes suaves y prendas fáciles de repetir.

**Sastrero**

Estructura y líneas pulidas sin necesidad de verse rígido.

**Preppy**

Tejidos limpios, códigos colegiales y una formalidad joven.

**Streetwear**

Siluetas amplias, gráficos y referencias urbanas con presencia.

**Deportivo**

Prendas técnicas y cómodas usadas como parte del look cotidiano.

**Utilitario**

Bolsillos, capas funcionales y materiales resistentes.

**Romántico**

Texturas suaves, curvas y detalles delicados.

**Bohemio**

Capas sueltas, textura y mezcla de materiales.

**Rebelde**

Cuero, oscuridad y piezas que rompen una composición demasiado pulcra.

**Vanguardista**

Proporciones inesperadas y prendas que exploran otra silueta.

---

### Paso 3 — Límites

**Etiqueta**

Tus límites

**Pregunta**

¿Qué no quieres que Formé te recomiende?

**Texto**

Separa lo que nunca usarías de lo que simplemente prefieres ver menos.

**Dos niveles**

- Evitar siempre
- Mostrar menos

**Opciones**

- Tacones
- Escotes pronunciados
- Prendas muy ceñidas
- Prendas muy cortas
- Transparencias
- Colores muy vivos
- Logos o gráficos grandes
- Looks muy formales
- Looks muy deportivos
- Otro

**Comportamiento**

- “Evitar siempre” excluye la opción de las recomendaciones.
- “Mostrar menos” reduce su prioridad, pero permite usarla cuando el contexto la justifique.

## 3. Calibración posterior

No forma parte del flujo inicial. Después de algunos usos, Formé puede mostrar una calibración breve, integrada al producto.

**Pregunta 1**

¿Cuál de estos looks usarías esta semana?

**Pregunta 2**

¿Qué cambiarías del que descartaste?

**Motivos**

- Color
- Silueta
- Prenda
- Calzado
- Formalidad
- No se siente como yo

La respuesta ajusta la capa aprendida del perfil sin borrar la calibración inicial.

## 4. Datos mínimos

```ts
type StyleCalibration = {
  version: 2
  completed: boolean
  presentationStart:
    | "mostly_masculine"
    | "mostly_feminine"
    | "mixed"
    | "no_preference"
  familyRatings: Array<{
    family: string
    affinity: number
    hardReject: boolean
    reasonTags: string[]
  }>
  hardAvoids: string[]
  softAvoids: string[]
  contexts: string[]
  primaryGoal: string
  exploration: number
}
```

### Prioridad para recomendaciones

1. Aplicar `hardAvoids` como filtros.
2. Usar el contexto solicitado.
3. Ordenar por afinidades visuales y aprendizaje posterior.
4. Reducir la prioridad de `softAvoids`.
5. Ajustar novedad según `exploration`.
6. Explicar qué decisiones llevaron a la recomendación.
